# **App Name**: SpendSmart

## Core Features:

- Expenditure Input: Allow users to input their daily expenditure, categorizing each entry as either 'Cash' or 'Mobile Money'.
- Target Setting & Monitoring: Enable users to set daily, weekly, and monthly expenditure targets. Implement real-time monitoring against these targets.
- Expenditure Reporting: Generate expenditure reports, broken down by 'Cash' and 'Mobile Money', for daily, weekly, and monthly periods.

## Style Guidelines:

- Primary color: Teal (#008080) for a sense of calm and control.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Gold (#FFD700) for highlighting target limits and warnings.
- Clean, minimalist layout with clear separation of input fields, targets, and reports.
- Use simple, intuitive icons to represent 'Cash' and 'Mobile Money'.
- Subtle animations for transitions and updates to expenditure reports.

## Original User Request:
Create for me an app that monitors my daily expenditure and gives me wanings when I exceed certain amounts daily, weekly and even monthly. it should also allow me to set targets for expenditure daily, weekly, and even monthly. Let it also generate reports on expenditure divided into cash and mobile money
